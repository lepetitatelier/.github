# Le Petit Atelier

*small workshop, big impact*

An open workshop in Akaroa, Banks Peninsula, Aotearoa New Zealand. Low-cost technology (3D printing, electronics,
recycling, repair) built for the local environment and community, with every design published under an open licence.

**[lepetitatelier.nz](https://lepetitatelier.nz)** · bonjour@lepetitatelier.nz

## The four rules

1. Every project repairs, reuses or protects something.
2. Every design is published under an open licence.
3. Recycled or reclaimed materials first.
4. No sponsor that conflicts with the mission.

## How the repos work

One repo per project, each with its files, build notes and history. Projects are described on
[lepetitatelier.nz/projects](https://lepetitatelier.nz/projects/). Designs are published here as each project is ready.
